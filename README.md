# ZhPath

Платформа изучения китайского языка. Сейчас: фронтенд-прототип и подготовка MVP.

- [План спринтов и задачи](docs/ROADMAP.md)
- [Содержание первого модуля HSK 1](docs/HSK1_MODULE.md)
- [Структура проекта и технические решения](docs/ARCHITECTURE.md)

Установка: `pnpm install --frozen-lockfile`.
Проверка типов: `pnpm typecheck`. Production-сборка: `pnpm build`.
Локальный запуск вне Figma: `pnpm dev` (порт по умолчанию 8443).

Данные ученика и обучения демонстрационные; авторизация, БД и ИИ ещё не подключены.
