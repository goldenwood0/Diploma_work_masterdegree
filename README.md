# ZhPath

Платформа изучения китайского языка. Реализованы спринты 0–3: структура фронтенда,
NestJS API, PostgreSQL, авторизация, онбординг, профиль, интерфейс ru/kk/en,
каталог HSK 1–6 и четыре пилотных урока с сохранением прогресса.
Следующий этап — упражнения и тесты.

Установка: `pnpm install --frozen-lockfile`.
Проверка типов: `pnpm typecheck`. Production-сборка: `pnpm build`.
Локальный запуск вне Figma: `pnpm dev` (порт по умолчанию 8443).

Для полного запуска следуйте инструкции спринта 1: нужны `.env`, Docker,
миграции и запущенный API. После сборки сервера загрузите уроки: `pnpm db:seed`.
Аккаунты и прогресс сохраняются в БД. Учебный материал требует методической проверки;
ИИ ещё не подключён. Локальная почта доступна в Mailpit на порту 8025.
