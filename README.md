# ZhPath

Веб-платформа изучения китайского языка (HSK) с интерфейсом и объяснениями
на русском, казахском и английском, админкой для преподавателя и ИИ-помощником.
Магистерский дипломный проект «Разработка приложения для обучения иностранным
языкам с интеграцией технологий искусственного интеллекта».

**Начать здесь:**

- [Состояние проекта](docs/STATUS.md) — что работает, что нет, как запустить.
- [План работ](docs/ROADMAP.md) — пять этапов до защиты и после неё.

Стек: React 19, TypeScript, Vite 8, Tailwind CSS 4; NestJS 11, Prisma 6,
PostgreSQL 17; ИИ через серверный адаптер OpenAI Responses API.

ИИ-помощник подключён, но настоящая модель ещё не дала ни одного ответа —
проверен только с тестовым адаптером. Учебный материал требует методической проверки.
