# ZhPath

Платформа изучения китайского языка. Реализованы спринты 0–2: структура фронтенда,
NestJS API, PostgreSQL, авторизация, онбординг, профиль и интерфейс ru/kk/en.
Следующий этап — каталог и уроки из базы данных.

- [Содержание первого модуля HSK 1](docs/HSK1_MODULE.md)
- [Структура проекта и технические решения](docs/ARCHITECTURE.md)
- [Спринт 1: запуск API, БД и почты](docs/SPRINT_1.md)
- [Спринт 2: профиль и три языка](docs/SPRINT_2.md)

Установка: `pnpm install --frozen-lockfile`.
Проверка типов: `pnpm typecheck`. Production-сборка: `pnpm build`.
Локальный запуск вне Figma: `pnpm dev` (порт по умолчанию 8443).

Для полного запуска следуйте инструкции спринта 1: нужны `.env`, Docker,
миграции и запущенный API. Аккаунты настоящие; учебные данные пока демонстрационные,
ИИ ещё не подключён. Локальная почта доступна в Mailpit на порту 8025.
