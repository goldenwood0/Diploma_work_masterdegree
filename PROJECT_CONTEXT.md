- React 19, TypeScript, Vite 8, Tailwind CSS 4; маршруты через hash.
- NestJS 11 с Express, Prisma **6.19.0**, PostgreSQL **17**.
- Zod проверяет входные данные и ответы клиентского API.
- ExcelJS + fflate для словарных `.xlsx`, загружаются динамически.
- CI: Node 22, pnpm **10.34.3**, PostgreSQL 17.
- UI: `http://127.0.0.1:8443`, API: `http://127.0.0.1:3001/api`.
- Vite проксирует `/api` на 3001. Настроенный APP_ORIGIN должен точно совпадать
  с адресом UI: `localhost` и `127.0.0.1` для этой проверки различаются.
- `compose.yaml`: PostgreSQL на `127.0.0.1:5433`, постоянный том
  `postgres-data`; Mailpit SMTP 1025, интерфейс 8025.
- Секреты в игнорируемом `.env`. Не выводить его целиком и не коммитить.

Обычный порядок после настройки `.env` по `.env.example`:

```powershell
npx --yes pnpm@10.34.3 install --frozen-lockfile
docker compose up -d
npx --yes pnpm@10.34.3 db:generate
npx --yes pnpm@10.34.3 db:deploy
npx --yes pnpm@10.34.3 server:build
npx --yes pnpm@10.34.3 db:seed
```

Затем API и Vite запускаются в отдельных процессах командами `server:dev`
и `dev` того же pnpm. Сначала проверить, не заняты ли порты работающим проектом.
`server:dev` запускает **собранный** `dist-server/main.js`, без watch: изменения
сервера требуют сборки и перезапуска. Состояние процессов между задачами не
гарантировано. Не удалять том БД для устранения проблем запуска.

На этой машине глобальный pnpm 12 пытался пересоздавать node_modules и падал
с отказом доступа; восстановлено через pnpm 10.34.3. Не обновлять инструменты

## БД и важные решения

Модели: User, UserSettings, Session, AccountToken, RoleChange;
Curriculum → CourseLevel → CourseUnit → Lesson → LessonBlock;
LessonChange, Quiz, QuizAttempt, LessonProgress; ReviewCard, ReviewEvent;
MediaAsset, MediaChange.

- Роли STUDENT, EDITOR, ADMIN. Регистрация не принимает привилегированную роль.
  Сессии в БД, cookie `zhpath_session` локально / `__Host-zhpath` в production.
  Пароли хешируются; токены хранятся в виде хешей.
- Изменяющие запросы требуют точный Origin и `X-ZhPath-Request: 1`.
- Смена роли проверяет версию, пишет аудит и отзывает сессии; защищены своя
  роль и последний администратор. Реальный аккаунт владельца не выбирать
  произвольно по адресу: в проверках использовались отдельные фикстуры.
- Уроки разблокируются по prerequisite и завершению актуальной версии.
  QuizAttempt хранит снимок результата; отправка защищена от повторов.
- `Lesson.revision` и `Quiz.revision` отражают изменения содержания;
  `Lesson.editVersion` защищает редакторские операции от устаревших записей.
- `Lesson.draft` — независимая JSON-копия title, minutes, blocks, quiz.
  `published=true` может сочетаться с editorialState DRAFT/REVIEW: ученику
  остаётся прежняя публикация. Черновик исключён из ученического ответа.
- Публикация рабочей копии атомарна; блоки и прогресс не сбрасываются при
  неизменном содержании. Изменённый тест сохраняет прежние попытки.
- Восстановление берёт состояние ПОСЛЕ выбранного события, создаёт черновик,
  пишет RESTORE с исходным ID. Автоматической публикации нет.
- Последняя миграция: `20260912123000_lesson_draft`, применена локально.
- Медиа WAV хранятся байтами в PostgreSQL вместе с авторством/лицензией.
  Архив скрывает файл из обычного выбора, но сохраняет существующие ссылки.

## Что не готово и ограничения

- ИИ-помощник — заглушка; нет серверного провайдера, лимитов и контекста.
- Не выполнены весь спринт 7, релизная приёмка, полное наполнение и методическая
  проверка HSK 1–6. Наличие фронтенда не подтверждает готовность функции.
- Админка пользователей пока управляет ролями, не полным жизненным циклом
  аккаунта. Медиа — PCM WAV (до 5 МиБ / 5 минут); другие загрузки не реализованы.
- CSV/Excel — слова одного блока, не обмен полными уроками. До 100 слов,
  файл до 1 МБ, ru/kk/en обязательны; Excel — один лист без формул.
- История редактора показывает 30 событий без сравнения и пагинации.
  Неполные старые снимки не восстанавливаются. Откат к отсутствию теста при
  существующем тесте отклоняется. Нет отмены независимого черновика;
  архивирование с таким черновиком недоступно.
- Production-деплой, проверенные резервные копии и мониторинг не подтверждены.
  Известны предупреждения Vite о конфиге и размере бандлов.
