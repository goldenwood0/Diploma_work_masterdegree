# Сравнение локальных моделей для ИИ-помощника

23.11.2026. Ollama 0.40.16, ноутбук с RTX 4050 Laptop (6 ГБ), 16 ГБ RAM.
Модели: `qwen2.5:7b` (4,7 ГБ) и `llama3.1:8b` (4,9 ГБ), обе в сжатии Q4.

Это техническая проверка автора, **не методическая приёмка**. Оценки китайского
и пиньиня проверены по материалу урока; казахские ответы оценены грубо (связность
и соответствие заданию) и требуют носителя языка.

## Как проверяли

- Урок `hsk1-greetings` из базы; материал собран так же, как в
  `TutorService.context` (один блок, `redact`, до 8000 символов).
- Системная инструкция — та же, что в приложении (`tutorInstructions`), плюс
  строка о языке ответа из `server/tutor-ollama.ts`.
- 5 режимов × 3 языка объяснения (ru, kk, en) + 1 попытка подмены инструкций.
- Одинаковые входы для обеих моделей, температура 0,3, лимит 1200 токенов.
- Ввод для проверки фразы: `你好吗？我是很好。` (ошибка: 是 перед прилагательным,
  правильно `我很好`). Для разбора ошибок — ответ «nǐ hǎo, оба слога третьим
  тоном» при правильном «ní hǎo».
- Скрипт: `scripts/tutor-compare.mjs`. Полные ответы: папка
  [ollama-2026-11-23](ollama-2026-11-23/).

Оценка: **2** — верно и по делу, **1** — частично (есть ошибка или не тот
язык/формат), **0** — неверно, вредно для ученика или бессвязно.

## Выводы

1. **Ни одна модель 7–8B не годится для свободных режимов без проверки.**
   В «проверке фразы» и «объяснении» обе выдают уверенные грамматические
   ошибки — это опаснее, чем отсутствие ответа.
2. **Разбор ошибок теста работает лучше всего** у обеих моделей: правильный
   ответ и объяснение уже есть во входных данных, модели остаётся пересказать.
   У llama — 6 из 6 баллов на всех трёх языках.
3. **llama3.1:8b в целом лучше (16 против 11)**, особенно на казахском, где qwen
   бессвязна. qwen лучше держит роль при подмене инструкций.
4. Материал урока трёхъязычный (ru/kk/en в одном тексте), поэтому модели
   подмешивают чужой язык. Отдавать модели только язык ученика — дешёвое
   улучшение.

## Рекомендации

- Использовать `llama3.1:8b` по умолчанию для локального режима.
- На показе демонстрировать «Разбор ошибок теста» и «Тренировочные вопросы».
- Перед включением для учеников: оставлять в материале только язык объяснения;
  проверить ответы с преподавателем; для «проверки фразы» нужна модель крупнее
  (облачная или 14B+, которая на 6 ГБ видеопамяти будет медленной).
