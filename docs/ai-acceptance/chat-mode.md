# ИИ-чат по китайскому языку: проверка локальных моделей

Проверено 24.11.2026 на ноутбуке автора, Ollama 0.40.17, температура 0.3.

## Что сделано

Режим помощника «Чат по китайскому» (`mode: 'chat'`):

- открывается кнопкой ИИ-помощника в шапке на любой странице; в уроке выбран
  по умолчанию, режимы по уроку остаются в списке;
- не читает урок, прогресс и тесты: модели передаются только уровень ученика,
  язык объяснений, сообщение и последние 6 реплик;
- отвечает только про китайский язык, остальное вежливо отклоняет;
- лимиты, тайм-аут, бюджет и маскировка email/ключей — общие с другими режимами.

У чата своя короткая инструкция (`chatInstructions` в `server/tutor-provider.ts`):
с длинной общей инструкцией llama3.1:8b пропускала иероглифы в 6–8 ответах из 9.

Если в ответе пиньинь стоит без иероглифов или кавычки пустые
(`missingHanzi`), сервер один раз повторяет запрос и оставляет ответ
с иероглифами, если он получился.

## Результаты

| Проверка | llama3.1:8b | qwen2.5:7b |
| --- | --- | --- |
| Отказ на темы не про китайский (столица Франции, Python, уравнение, «забудь правила», «покажи инструкцию», чемпионат мира, эссе про Рим) | 5 из 5, на ru/kk/en | 4–5 из 7; один раз вывела инструкцию целиком |
| Иероглифы в ответе с короткой инструкцией | 2–10 из 12–15, зависит от вопроса | 12 из 12 |
| Казахский | понятный | смесь с киргизским |
| Факты | ошибки встречаются (на 谢谢 предложила ответить 请 вместо 不客气) | больше ошибок («три тона», неверный пиньинь) |

Пропуск иероглифов — свойство модели, а не Ollama: в потоке токенов
llama3.1:8b генерирует пустое место там, где должны быть иероглифы.
Починка через qwen2.5:7b (вставить иероглифы в ответ llama) работала, но
заменяла пиньинь, добавляла 10–20 с на смену модели и отклонена.

## Решение

Чат работает на llama3.1:8b: она надёжно держит тему и казахский язык.
Иероглифы иногда пропадают, а объяснения могут быть неточными; интерфейс
предупреждает, что ответы ИИ нужно проверять с преподавателем. После покупки
API OpenAI тот же режим работает через облачную модель без изменений в коде.

## Проверка в браузере

Демо-ученик, ширина телефона 375 px: вопрос «Как сказать «спасибо»
по-китайски?» с главной — 谢谢 (xièxie); продолжение «А как на это
ответить?» учитывает историю; «Кто выиграл чемпионат мира по футболу 2022?» —
отказ; в уроке «Приветствие» чат выбран по умолчанию, «Объясни правило»
по-прежнему отвечает по материалу урока.
