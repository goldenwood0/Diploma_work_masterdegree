# Аудит мобильной навигации ZhPath — 2026-10-16

Изменены App, MobileNavButton, NavButton, стили, viewport и оформление панели ИИ. Существующие изменения уроков, API и бизнес-логики сохранены.

## Исправления

- Видимые подписи всех четырёх разделов, включая профиль; перенос вместо обрезки.
- Активный раздел отмечен рамкой, фоном и aria-current. В уроке активны «Курсы».
- Нижняя навигация используется до 1024px, чтобы на планшете подписи не теснили шапку.
- ИИ перенесён в шапку: у кнопки есть собственное место, она не плавает над заданиями.
- Размер навигации измеряется ResizeObserver, включая переносы и safe-area; под неё резервируется место. Scroll padding учитывает обе панели при фокусировке.
- Логотип — настоящая кнопка с названием «ZhPath — Главная». Видимый контрастный фокус, понятные доступные названия, декоративные иконки скрыты от скринридера.
- Кнопки навигации, логотипа, ИИ и закрытия панели имеют область нажатия минимум 44px.
- viewport-fit=cover и env(safe-area-inset-*) для панелей.

## Проверки

Chrome headless, production preview, изолированные ответы API (не реальные аккаунты/прогресс).

Для каждого языка ru/kk/en и каждой ширины 320/375/768/1280 проверены главная, каталог, длинный урок, повторение и профиль: 60 сочетаний. Проверены отсутствие горизонтального скролла, видимые подписи, единственный активный пункт, размеры целей, размещение ИИ и доступность последних кнопок над нижней панелью.

В 12 сочетаниях проверены реальные события клавиатуры: Tab/Shift+Tab по форме, Enter для логотипа, Space для профиля, открытие ИИ, цикл фокуса, Escape, возврат фокуса. Для мобильных ширин дополнительно проверены удвоенные подписи навигации и имитация нижнего отступа 34px: высота резервируется корректно. Это не эмуляция аппаратного safe-area.

Всего 81 запись проверки, см. outputs/navigation-audit/results.txt и 12 PNG рядом. TypeScript, production build и test:i18n проходят. Сборка сообщает предупреждения Vite о конфигурации и крупных чанках.

Запуск: установить playwright вне проекта, задать NAV_QA_PLAYWRIGHT путём к его пакету, запустить production preview на 127.0.0.1:8443 и node scripts/test-navigation.cjs. Тест использует установленный Google Chrome и подменяет все /api/** только в своём браузерном контексте.

## Ограничения и реальный телефон

- Нужны Safari iOS и Chrome Android: вырезы, home indicator, жестовая панель, поворот экрана, сворачивание адресной строки.
- Проверить экранную клавиатуру в ИИ и профиле, прокрутку и достижимость нижних полей на коротком экране.
- Проверить VoiceOver/TalkBack: названия, активный раздел, порядок и возврат фокуса; удобство касаний одной рукой.
- Удвоение подписей навигации проходит. Отдельный эксперимент с увеличением корневого шрифта ВСЕЙ страницы до 200% при ширине 320px обнаружил переполнение страницы профиля до 420px. Полная адаптация страниц под такой режим не входит в эти исправления навигации; системное увеличение текста остаётся отдельной задачей.
- Проверки используют учебные фикстуры: реальные наборы заданий и клавиатуру телефона необходимо проверить отдельно.
