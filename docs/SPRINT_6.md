## Реализовано

- Экран `/#/content`, ссылка «Управление уроками» для EDITOR/ADMIN.
- Названия ru/kk/en и длительность редактируются в черновике.
- Черновик → проверка → публикация → архив → черновик.
- Публикация и архивирование требуют ADMIN. STUDENT не получает доступ к API.
- Опубликованные уроки защищены от непосредственного редактирования.
- При архивировании урок скрывается от учеников. Это текущая модель: независимого
  черновика поверх опубликованной версии пока нет.
- editVersion защищает от устаревших записей. Транзакция сохраняет изменение
  и журнал с actorId, временем и снимками метаданных до/после.
- Предпросмотр текстовых/словарных блоков, последние 30 событий журнала.
  Аудио в предпросмотре пока не воспроизводится.

API: GET `/api/content/lessons`, GET/PATCH `/api/content/lessons/:id`,
POST `/api/content/lessons/:id/state`. PATCH содержит `{version,title,minutes}`;
изменение состояния — `{version,state}`. Проверяются сессия, права и CSRF.
Публикация требует названий на трёх языках и наличия блоков; полная редакторская
валидация блоков и медиа будет при добавлении их редактирования.

Изменение названия не сбрасывает учебный прогресс: editVersion отдельно от
учебной revision. Старые опубликованные записи распознаются по published=true.
Новые поля по умолчанию DRAFT/0; миграция не меняет доступность прежних уроков.

Запуск: Docker, `pnpm db:deploy`, `pnpm db:generate`, `pnpm server:build`,
`pnpm server:dev`, `pnpm dev`. На Windows остановить API перед db:generate.
Существующим пользовательским аккаунтам роли автоматически не назначались.
Для доступа нужен аккаунт с ранее назначенной ролью EDITOR или ADMIN.
