# Спринт 2 — профиль, онбординг и три языка

## Результат

После первого входа ученик задаёт имя, опыт, цель, стартовый HSK, время занятий,
часовой пояс и языки. Настройку нельзя случайно пропустить через другой адрес:
пока onboardingCompletedAt отсутствует, кабинет показывает форму онбординга.
После сохранения открывается главная. Те же поля доступны в профиле.

Настройки сохраняются в PostgreSQL и восстанавливаются при новом входе.
Язык интерфейса (`uiLanguage`) и объяснений (`explanationLanguage`) независимы.
Форма поддерживает ru/kk/en; локализованы существующие экраны, навигация, формы
авторизации и отображаемые сообщения ошибок. В демонстрационном уроке переводы
слов и текст объяснения используют язык объяснений, китайский и pinyin сохраняются.

Выбор языка в форме сразу даёт предпросмотр. Для записи в аккаунт нужно нажать
«Сохранить настройки» или «Начать обучение». До входа последний язык сохраняется
только в браузере; при входе источником истины становится аккаунт.
Атрибут html lang соответствует текущему языку интерфейса.

## API и миграция

`PATCH /api/profile`, с cookie сессии, Origin и X-ZhPath-Request.
Тело: name, uiLanguage, explanationLanguage, timezone, dailyGoalMinutes,
experience, goal, startLevel, remindersEnabled, необязательный completeOnboarding.
Ответ: `{ user }` по тому же контракту, что `/api/auth/me`.
Сервер определяет пользователя из сессии; userId, role и другие лишние поля
отклоняются. Имя и настройки обновляются одной вложенной операцией Prisma.

Допустимы: HSK 1–6; 5–60 минут с шагом 5; поддерживаемый средой часовой пояс IANA;
опыт beginner/some/experienced; цель communication/study/work/exam.
Повторное сохранение не стирает завершённый онбординг.

Миграция `20260909134229_profile_onboarding` добавляет поля с безопасными
значениями по умолчанию, не удаляет аккаунты и сессии. Существующие ученики
увидят онбординг при следующем входе.

После обновления кода: `pnpm db:generate`, `pnpm db:deploy`, `pnpm server:build`;
перезапустить API (`pnpm server:dev`). Остальной запуск — в SPRINT_1.md.

## Локализация

Словарь: `src/i18n/messages.ts`, провайдер: `LanguageProvider.tsx`.
Русский исходный текст служит ключом и fallback: отсутствующий или пустой
перевод возвращает русский текст. Новую строку нужно добавить в en и kk.
UI использует `t`, учебные объяснения — `explain`.
Серверные сообщения пока сопоставляются по исходному тексту; при расширении API
лучше перейти на стабильные коды ошибок. Письма авторизации пока русские.

## Что остаётся на следующие этапы

Учебные показатели, каталог и содержание пока демонстрационные: выбор HSK
сохраняет предпочтение, но не наполняет курс и не меняет правила доступа.
Предпочтение напоминаний сохраняется; рассылка появится в спринте 7.
Аватар, загрузка медиа и другие возможности полного ТЗ не входят в этот этап.
Переводы учебных материалов требуют методической и языковой проверки до публикации.
Vite по-прежнему предупреждает о размере общего JS-бандла и будущей смене
загрузчика конфигурации; сборка проходит. Оптимизацию загрузки выполнить до beta.
