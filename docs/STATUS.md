## Коротко

Веб-платформа изучения китайского языка (HSK) с интерфейсом и объяснениями
на русском, казахском и английском, админкой для преподавателя и ИИ-помощником.
Инженерная основа готова; для защиты не хватает настоящих ответов ИИ,
контента и проверки на реальных людях.

Код: ветка `practice/ux-2`, открыт pull request №1 в `main`, CI проходит.

## Что не готово

| Проблема | Почему важно | Что нужно |
| --- | --- | --- |
| Настоящая модель ИИ не дала ни одного ответа | Главный тезис диплома не доказан | Пополнить баланс OpenAI |
| 4 урока, тесты по 2 вопроса | Нечего показать как курс | Довести модуль HSK 1 до 10–15 уроков |
| Нет методической проверки | Ошибки в китайском или переводах на защите | Показать преподавателю |
| Урок — «чтение, затем тест» | Слабее Duolingo по вовлечению | Одно задание на экран, мгновенная проверка |
| Не проверено на телефоне, с микрофоном, письмом пальцем | Неизвестно, работает ли в реальности | Проверка на устройстве |
| Права на аудио не подтверждены | Риск при публикации | Записать своё или подтвердить лицензии |
| Dev-сервер Vite зависает | Неудобно разрабатывать | Показ через сборку (ниже) |
| Нет деплоя | Нельзя дать ссылку | После защиты |

## Как запустить для показа

Нужны Docker Desktop и заполненный `.env` (по `.env.example`). База — контейнер
`zhpath-db-1` на порту 5433, данные в томе `zhpath_postgres-data`.

```powershell
docker compose up -d db
npx --yes pnpm@10.34.3 server:build
npx --yes pnpm@10.34.3 build
```

В двух отдельных терминалах:

```powershell
node --env-file=.env dist-server/main.js
```

```powershell
npx --yes pnpm@10.34.3 preview --host 127.0.0.1 --port 8443 --strictPort
```

Открыть `http://127.0.0.1:8443`. Без hot reload: после правки кода повторить
обе сборки. ИИ включается переменными `OPENAI_API_KEY` и
`ZHPATH_TUTOR_ENABLED=true` в `.env`; без них панель честно сообщает, что ИИ
не настроен. Подробности и прошлые проблемы запуска — [LOCAL_RUN.md](LOCAL_RUN.md).

## Показ преподавателю

Интерфейс главной, каталога, урока и теста приведён к макетам ПР5–ПР6 для
телефона (до 767 px), планшета (768–1199 px) и компьютера (от 1200 px).

### Запуск (PowerShell, папка проекта)

Docker Desktop должен быть запущен. Порты 8443, 3001 и 5433 должны быть
свободны (`Get-NetTCPConnection -State Listen -LocalPort 8443,3001,5433`);
чужие процессы не останавливать.

```powershell
docker compose start db
docker inspect zhpath-db-1 --format '{{.State.Status}} {{.State.Health.Status}}'
npx --yes pnpm@10.34.3 server:build
npx --yes pnpm@10.34.3 build
```

Дождаться `running healthy`. Если `server:build` сообщает об ошибках типов
Prisma (`Property 'PrismaClientKnownRequestError' does not exist…`), после
переустановки `node_modules` пропал сгенерированный клиент: выполнить
`npx --yes pnpm@10.34.3 exec prisma generate` (меняет только `node_modules`,
не базу) и повторить сборку.

В двух отдельных терминалах:

```powershell
node --env-file=.env dist-server/main.js
```

```powershell
npx --yes pnpm@10.34.3 preview --host 127.0.0.1 --port 8443 --strictPort
```

Открыть `http://127.0.0.1:8443`. После правок кода повторить `build` и
обновить страницу (Ctrl+F5).

### Учётная запись

Для показа — аккаунт с ролью **студента** с пройденным первым уроком: у
редактора и администратора над каждой страницей видны кнопки управления
контентом. Email и пароль хранятся у автора и в репозиторий не записываются.
Перед показом войти заранее и проверить, что онбординг пройден.

### Сценарий на 5 минут

1. **Вход** (0:30). Экран входа, выбор языка интерфейса ru/kk/en.
2. **Главная** (0:45). Блок «Следующее учебное действие» с рекомендацией,
   карточка «Сегодня» с дневной целью, «Выберите следующий шаг».
3. **Каталог** (1:00). Панель фильтров слева: поиск по названию или пиньиню
   без тонов, уровень, статус; блок прогресса; карточки по 3 в ряд, закрытые
   уроки с замком. Поиск из шапки открывает каталог с запросом.
4. **Урок** (1:00). Блоки урока, аудио с носителем языка, скорость,
   транскрипт и перевод, запись голоса для самопроверки.
5. **Тест** (0:45). Один вопрос на экран, счётчик «Вопрос N / M», крупные
   варианты ответа, «Следующий вопрос», «К материалу»; черновик сохраняется
   в браузере.
6. **Результат** (0:30). «Тест пройден · N/M», разбор каждого ответа,
   история попыток, следующий урок открывается в каталоге.
7. **Смена ширины окна** (0:30). Сузить окно или открыть DevTools →
   Device Toolbar: 1440 → 768 (шапка с «Ещё», «Фильтры · N», 2 карточки) →
   390 (нижняя навигация, «Продолжить обучение» первым, фильтры во весь
   экран, кнопки теста закреплены внизу).

### Отличия от макетов (согласованы)

- Логотип «中» вместо «Z»: знак сразу говорит о китайском языке.
- В шапке есть кнопка ИИ-помощника; колокольчика нет (уведомлений нет).
- В фильтрах нет «Навыка» и кнопки «Применить»: у уроков нет поля навыка,
  фильтры применяются сразу.
- В карточке урока нет пиньиня, описания и «Подробнее» — этих данных и
  отдельной страницы нет; в плитке номер урока.
- Тест встроен в конец урока, а не открыт отдельным экраном.
- На телефоне нет меню-гамбургера: все разделы в нижней навигации.
- Шрифт Manrope вместо Inter.
- В повторении и профиле часть элементов меньше 44 px (вне сценария показа).

## Проверки

CI на GitHub (`.github/workflows/checks.yml`) при каждом изменении PR запускает:
типы, переводы, CSV/Excel, голос, черты, серверные тесты на чистой PostgreSQL
(включая тесты ИИ с подменённым провайдером) и сборку.

Локально без базы можно запустить: `typecheck`, `test:i18n`, `test:csv`,
`test:excel`, `test:voice`, `test:strokes`, `test:stroke-matching`, `build`.
`test:server` требует базу и создаёт в ней временные данные — не запускать на
базе с настоящими аккаунтами.
