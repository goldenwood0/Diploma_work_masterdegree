# ZhPath — план работ

Обновлён 12.11.2026 после переоценки проекта. Прежний план из десяти спринтов
с историей проверок сохранён в [ROADMAP_ARCHIVE_2026-09.md](ROADMAP_ARCHIVE_2026-09.md).

## Главный принцип

Ничего нового в админке, почте и инфраструктуре, пока ученик не может пройти
полноценный модуль с работающим ИИ. Тема диплома — приложение для обучения
языку с интеграцией ИИ, поэтому ядро работы — опыт ученика и ИИ.

## Где проект сейчас

Готово и работает (по автоматическим проверкам и журналам спринтов):

- Аккаунты, профиль, интерфейс и объяснения на ru/kk/en.
- Каталог HSK 1–6, уроки с последовательной разблокировкой, шесть типов заданий,
  тесты с историей попыток.
- Личный словарь с уровнями HSK, интервальное повторение.
- Статистика: активное время, серия дней, точность по темам и навыкам.
- Запись голоса для самопроверки, тренажёр письма по чертам.
- Админка: редактор уроков и тестов, черновики, публикация, версии, роли, медиатека.
- ИИ-помощник: пять режимов, включая разбор ошибок теста; лимиты и бюджет.
- CI на GitHub проходит.

Не готово:

- Настоящая модель ИИ не дала ни одного ответа (на счёте OpenAI нет средств).
- Контента мало: четыре урока, тесты по два вопроса.
- Методической проверки китайского, пиньиня, переводов и ответов ИИ не было.
- Урок устроен как «чтение, затем тест», без мгновенной проверки ответа.
- На реальном телефоне, с микрофоном и письмом пальцем не проверялось.
- Dev-сервер Vite зависает; показ идёт через сборку и preview.
- Деплоя нет.

## Этапы

Сроки условные и зависят от даты защиты. Одновременно ведём один этап.

### 1. Зафиксировать состояние (1–2 дня)

- [ ] Влить pull request №1 в `main`.
- [ ] Закрыть спринты 6–8 как «сделано в объёме пилота»; отложенные задачи
      перенести в раздел «После защиты».
- [ ] Заменить журналы одной страницей «что готово / что нет».

Готово, когда: `main` содержит весь код, а состояние проекта понятно с одной страницы.

### 2. Оживить ИИ (несколько дней)

- [ ] Пополнить баланс OpenAI (делает владелец аккаунта).
- [ ] Получить настоящие ответы во всех пяти режимах на ru/kk/en.
- [ ] Проверить устойчивость к попыткам подмены инструкций.
- [ ] Сохранить обезличенные примеры ответов для диплома.
- [ ] Проверить кнопку «Разобрать ошибки с ИИ» в браузере.

Готово, когда: ученик в основном приложении получает осмысленный ответ модели,
а расход учтён в журнале бюджета.

### 3. Наполнить один модуль (1–2 недели)

- [ ] Довести модуль HSK 1 до 10–15 уроков по 6–10 заданий.
- [ ] Записать или подобрать аудио с подтверждёнными правами.
- [ ] Показать китайский, пиньинь и переводы преподавателю; исправить замечания.
- [ ] Опубликовать через админку.

Готово, когда: модуль проходится от первого урока до итогового теста и принят
преподавателем.

### 4. Урок «как в Duolingo» (1–2 недели)

- [ ] Одно задание на экран с мгновенной проверкой ответа.
- [ ] Кнопка «объясни ошибку» под неверным ответом (ИИ).
- [ ] Очки за урок и уровень ученика.
- [ ] Повторение слабых слов внутри урока.
- [ ] Проверка на телефоне: вёрстка, микрофон, письмо пальцем.

При нехватке времени оставить первые два пункта и проверку на телефоне.

Готово, когда: урок занимает 3–5 минут и ученик видит результат каждого ответа сразу.

### 5. Доказательства для диплома (1–2 недели)

- [ ] Дать 5–10 людям пройти модуль; собрать результаты и отзывы.
- [ ] Оценить ответы ИИ с преподавателем.
- [ ] Починить dev-сервер или закрепить показ через сборку.
- [ ] Отрепетировать демонстрацию; подготовить список ограничений.

Готово, когда: есть данные о реальном использовании и сценарий показа проходит
без сбоев.

## После защиты

- Деплой: HTTPS, резервные копии с проверкой восстановления, мониторинг.
- Автоматическая оценка произношения.
- Разделение сервера на модули со слоем сервисов; общий лимитер и хранилище
  бюджета ИИ для нескольких процессов.
- Загрузка страниц админки отдельно от ученических.
- Рабочая почта и включение напоминаний.
- Отложенное из админки: обмен полными уроками, сравнение версий, отмена черновика,
  блокировка аккаунтов, MP3 и изображения в медиатеке.
