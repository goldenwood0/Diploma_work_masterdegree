# Спринт 3 — каталог и уроки

Реализован 10.09.2026. Каталог, содержание уроков и прогресс теперь загружаются
из PostgreSQL. Доступны структура HSK 1–6 и четыре учебных урока первого модуля
HSK 1: приветствие, представление, вопрос об имени, вежливые слова.

## Запуск

После установки зависимостей и настройки `.env` по инструкции спринта 1:

```powershell
docker compose up -d --wait
pnpm db:generate
pnpm db:deploy
pnpm server:build
pnpm db:seed
pnpm server:dev
```

В другом терминале: `pnpm dev`. Адрес: http://127.0.0.1:8443.
После входа и онбординга откройте «Курсы».

Seed добавляет недостающие записи и не перезаписывает существующие уроки,
правки редактора и прогресс учеников. Повторный запуск безопасен. Обновление
существующего содержания требует отдельной миграции/редакторского действия.
Нельзя удалять Docker volume при обычном обновлении.

## Поведение

- Иерархия: Curriculum → CourseLevel → CourseUnit → Lesson → LessonBlock.
- Локализации `ru/kk/en` хранятся в JSONB полях названий и содержания.
  Интерфейс и объяснения выбирают язык независимо. Клиент проверяет структуру
  ответа через Zod; JSX отображает текст без вставки HTML.
- Три вида блоков: словарь, чтение/объяснение, аудио. Урок открывается по
  собственному адресу `/#/lessons/<slug>`.
- «Продолжить» сохраняет завершение текущего блока. Возобновление открывает
  первый непройденный блок; возвращение к уже прочитанным блокам не уменьшает
  достигнутый прогресс. Завершённый урок можно перечитать.
- Прогресс связан с пользователем из сессии. Идентификатор другого пользователя
  в запросе не принимается. После нового входа на другом устройстве восстанавливается
  тот же достигнутый блок. Это сохранение по действиям, не мгновенная синхронизация
  всех открытых вкладок: для чтения изменений другой вкладки обновите урок.
- Следующий урок открывается после завершения актуальной версии предыдущего.
  Проверка работает на сервере для чтения и записи, включая прямые ссылки.
- Сохранение выполняется в serializable-транзакции. Повтор запроса идемпотентен;
  старые запросы не откатывают прогресс, перескок через блоки запрещён.
  При конфликте параллельных записей возвращается 409 и возможность повтора.
- При существенном изменении порядка/состава блоков нужно увеличить `revision`.
  Старая вкладка получит 409. Новая версия начинается с первого блока, зависимые
  уроки требуют её завершения. Полная история версий и миграция достижений —
  отдельная задача редакторского процесса, не реализованы в этом спринте.
- Главная показывает количество опубликованных и завершённых уроков и предлагает
  продолжить начатый или начать первый доступный. Демонстрационные проценты,
  серии дней и очередь карточек с этих экранов убраны.

## Аудио и содержание

В первом уроке используется запись «你好» Sjors Provoost от 15.02.2011:
[источник](https://commons.wikimedia.org/wiki/File:Zh_n%C7%90_h%C7%8Eo.ogg),
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
Файл не изменён; автор, источник и лицензия указаны непосредственно у плеера.
Запись воспроизводится с Wikimedia; при недоступности источника появляется
ошибка и кнопка повтора. Скорости 0.75×/1×/1.25×, зацикливание, независимые
переключатели транскрипта и перевода. Автовоспроизведения нет.

Это пилотный учебный материал, требующий методической и языковой проверки.
Остальные три урока пока содержат текст и словарь, без отдельных аудиозаписей.
HSK 2–6 показывают состояние «Материалы готовятся». Упражнения, оценка знаний
и тест модуля относятся к спринту 4. Кнопка завершения подтверждает чтение
материала, а не проверенное владение языком. ИИ и SRS ещё не подключены.

## Проверки

- TypeScript frontend/backend, production-сборка, проверка 180 ключей перевода.
- 15 API-тестов на PostgreSQL: 10 предыдущих и 5 для доступа к урокам,
  изоляции, второй сессии, порядка блоков, повторов, гонок и смены версии.
- Повторная загрузка seed без дубликатов; прогресс остаётся сохранённым.
- Браузер: первый блок → обновление → продолжение на втором → аудио → завершение
  → разблокировка второго урока и переход по его адресу. Запись загрузилась
  без ошибки, воспроизводилась со скоростью 0.75× и повтором; перевод включается.
- Английский интерфейс и казахские объяснения проверены вместе в браузере.
- CI применяет миграции, дважды запускает seed, проверяет типы, переводы, API и сборку.

Полный аудит мобильных устройств, доступности, качества аудио и методики
остаётся в плане выпуска. Сборка сообщает предупреждения Vite о будущей загрузке
конфига и размере общего JS-файла; ошибок сборки нет.
