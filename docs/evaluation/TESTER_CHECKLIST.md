# Чек-лист тестировщика ZhPath

Для экспертной оценки автором (см. [EXPERT_REVIEW.md](EXPERT_REVIEW.md)).
Проходите как новичок, который не знает китайского и видит сайт впервые.
Лучше на телефоне по Wi‑Fi (как запустить — [STATUS.md](../STATUS.md), «Показ
как на телефоне или планшете»), затем ещё раз на компьютере.

Время: 40–60 минут. Записывайте всё, что заставило остановиться, перечитать,
нажать не туда или удивило. Мелочей не бывает.

## Подготовка

- [ ] Сайт запущен, Ollama работает, Mailpit запущен (`docker compose up -d mail`).
- [ ] Новый аккаунт (не демо-ученик): например `tester.p01@zhpath.local`.
- [ ] Устройство: ☐ телефон ☐ компьютер. Язык интерфейса: ☐ ru ☐ kk ☐ en.

## Проверка по принципам Нильсена

После задач пройдитесь по списку и запишите конкретные места.

| № | Принцип | Вопрос себе | Где нарушено | Серьёзность 0–4 |
| --- | --- | --- | --- | --- |
| 1 | Видимость состояния | Всегда ли понятно, где я и что происходит (загрузка, сохранение, прогресс)? | | |
| 2 | Соответствие реальному миру | Понятны ли слова и сообщения новичку, без технических терминов? | | |
| 3 | Свобода и контроль | Можно ли легко вернуться, отменить, выйти? | | |
| 4 | Согласованность | Одинаковые ли кнопки и слова на разных экранах? | | |
| 5 | Предотвращение ошибок | Предупреждает ли сайт до ошибки? | | |
| 6 | Узнавание, а не запоминание | Не нужно ли помнить что-то с прошлого экрана? | | |
| 7 | Гибкость и эффективность | Есть ли короткие пути для частых действий? | | |
| 8 | Минималистичный дизайн | Нет ли лишнего текста и элементов? | | |
| 9 | Помощь в ошибках | Понятно ли, что пошло не так и как исправить? | | |
| 10 | Помощь и документация | Есть ли подсказка там, где новичок застрянет? | | |

Серьёзность: 0 — не проблема; 1 — косметика; 2 — небольшая; 3 — серьёзная;
4 — катастрофа.
