# Пилот с участниками (этап 5 ROADMAP)

Цель — 5–10 человек проходят модуль HSK 1 в ZhPath, после чего заполняют
анкету. Из базы и анкет получается отчёт для главы диплома.

## Материалы

- [EXPERT_REVIEW.md](EXPERT_REVIEW.md) — экспертная оценка по принципам Нильсена
  и когнитивный проход: найденные проблемы и что работает хорошо. Основной
  метод оценки, пока пилот с участниками не проведён.
- [TESTER_CHECKLIST.md](TESTER_CHECKLIST.md) — чек-лист для автора-тестировщика.

- [QUESTIONNAIRE.md](QUESTIONNAIRE.md) — анкета ru/kk: SUS (удобство), вопросы
  об обучении и ИИ, открытые вопросы.
- [responses-template.csv](responses-template.csv) — шаблон для ввода ответов.
- `scripts/pilot-report.mjs` — отчёт: прохождение, точность первой попытки,
  темы и задания с ошибками, SUS и анкета. Только читает базу.

## Порядок

1. **До пилота.** Решить, какие уроки проходят участники: опубликованные
   сейчас 4 урока и тест модуля 1, либо модуль целиком после проверки
   преподавателем и публикации ([hsk1-content](../hsk1-content/README.md)).
   Запустить приложение по разделу «Показ преподавателю» в
   [STATUS.md](../STATUS.md), Ollama и Mailpit (`docker compose up -d mail`).
2. **Аккаунты.** Каждый участник регистрируется сам — на ноутбуке или с
   телефона по Wi‑Fi (см. «Проверка на телефоне» в
   [LOCAL_RUN.md](../LOCAL_RUN.md)). Email может быть условным
   (`p01@zhpath.local`): письмо подтверждения придёт в Mailpit
   (http://127.0.0.1:8025), автор открывает его и нажимает ссылку.
3. **Список участников.** Вести `output/participants.csv` (вне git):
   ```
   code,email
   P01,p01@zhpath.local
   ```
   Имя и настоящий email в репозиторий и отчёт не попадают.
4. **Сессия (20–40 мин).** Участник проходит уроки и тесты сам; автор не
   подсказывает, а записывает затруднения. Попросить хотя бы раз нажать
   «Объясни ошибку».
5. **Анкета.** Сразу после сессии. Ответы перенести в
   `output/responses.csv` по шаблону (код вместо имени).
6. **Отчёт.**
   ```powershell
   node --env-file=.env scripts/pilot-report.mjs --participants output/participants.csv --survey output/responses.csv --out output/pilot
   ```
   Результат: `output/pilot/REPORT.md` и `output/pilot/participants-results.csv`.
   Перед публикацией в дипломе проверить, что в открытых ответах нет имён.

## Что не измеряется

- Ответы ИИ-помощника не сохраняются в базе — только через анкету (B3, B4,
  D3) и наблюдение.
- SUS измеряет воспринимаемое удобство, а не результат обучения; результат —
  точность первой попытки и пункт B6 (самооценка).
- 5–10 участников — качественная оценка, без статистической значимости.
