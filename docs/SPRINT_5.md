# Спринт 5 — личный словарь и SRS

Реализован 10.09.2026. Раздел «Повторение» содержит личный словарь, поиск по
иероглифам/пиньинь/переводам, избранное, заметки и очередь карточек.

Слова добавляются из словарных блоков завершённых опубликованных уроков.
После зачёта теста импорт выполняется в той же транзакции; для старых аккаунтов
при открытии раздела вызывается безопасный повторный импорт. Ключ слова —
иероглифы + пиньинь; повторный импорт не перезаписывает заметки и расписание.
Словарь охватывает изученные слова, а не весь китайский язык.

## Расписание

Простой детерминированный алгоритм MVP, без заявления о реализации SM-2/FSRS:

| Оценка | Следующее повторение |
| --- | --- |
| Ещё раз | Через 10 минут, интервал и серия успешных ответов сбрасываются |
| Трудно | Предыдущий интервал × 1.2 с округлением вверх, минимум день |
| Хорошо | Предыдущий интервал × 2, минимум день |
| Легко | Предыдущий интервал × 3, минимум 4 дня |

Максимальный интервал — 365 дней. Даты хранятся в UTC; день интервала равен
24 часам. Счётчик сегодняшних оценок и лимит новых карточек используют календарную
дату в часовом поясе профиля. Лимит фиксирован: 10 впервые оценённых карточек
за день. Повторные оценки уже введённых карточек этот лимит не расходуют.
Сначала очередь отдаёт наступившие повторения, затем доступные новые карточки.
Досрочная оценка отклоняется сервером. Обновите очередь, когда наступит срок.

Режимы: иероглифы → перевод, перевод → иероглифы, пиньинь → иероглифы/перевод,
аудио → ответ. Это самопроверка: сначала «Показать ответ», затем оценка.
Аудиозапись пока есть только у 你好, с атрибуцией Sjors Provoost / CC BY-SA 3.0
из спринта 3. Для остальных слов показано отсутствие записи и предлагается
другой режим. Полный набор аудио остаётся частью подготовки контента к выпуску.

## Хранение и API

`ReviewCard` хранит содержание, заметку, избранное, версию и дату повторения.
`ReviewEvent` хранит оценку, дату, ключ повторного запроса и итоговое расписание.
История в интерфейсе — последние 30 событий; в БД сохраняются все.

- POST `/api/reviews/sync`: добавить слова из уже завершённых уроков.
- GET `/api/reviews`: словарь, очередь, лимиты и история текущего пользователя.
- PATCH `/api/reviews/:id`: заметка до 2000 символов и/или избранное.
- POST `/api/reviews/:id/rate`: `{ requestId, version, rating }`.

Сессия обязательна, записи защищены CSRF и проверкой владельца. Оценка и событие
сохраняются в serializable-транзакции. Повторный requestId не двигает дату второй
раз; изменение содержимого повтора, устаревшая версия и гонки возвращают 409.
При сетевом сбое повтор той же оценки использует прежний requestId.

Миграция: `pnpm db:deploy`, затем `pnpm db:generate` (API остановить на Windows),
`pnpm server:build`, `pnpm server:dev`. Фронтенд — `pnpm dev`.
Новый seed для карточек не нужен: данные привязаны к завершённым урокам ученика.

## Проверки и границы

25 автоматических проверок, типы, 242 ключа переводов и production-сборка прошли.
Добавлены проверки импорта без дубликатов, изоляции заметок, повторной оценки,
параллельных запросов, дневного лимита, часового пояса и интервалов через смену DST.
В браузере проверены импорт трёх слов из первого урока, заметка, избранное,
оценка «Хорошо» и уменьшение очереди.

Лимит пока не настраивается, расписание общее для всех режимов, самопроверка
не оценивает произношение. API выдаёт весь личный словарь — допустимо для пилота;
перед большим каталогом потребуются пагинация и оптимизация импорта.
Изменение часового пояса пересчитывает локальные дневные счётчики; это учебный
лимит, не защита от намеренного обхода. Редакторское обновление снимков слов
и полнота аудио относятся к дальнейшей работе с контентом.
