# Черновики тестов ZhPath

Черновик хранится в localStorage текущего браузера. Это позволяет записывать
каждое изменение синхронно даже без сети. Между устройствами он не переносится;
очистка данных браузера удаляет черновик.

Ключ включает ID пользователя и теста. Запись содержит версию формата, ID
пользователя/теста, quizRevision, lessonRevision, частичные ответы и requestId
неподтверждённой отправки. Обе версии проверяются: API отклоняет отправки при
изменении любой из них. editVersion редактора не используется, поскольку
сохранение редакторского черновика ещё не меняет опубликованные задания.

QuizPanel получает пользователя из текущего аккаунта и перемонтируется при его
смене. GET/POST теста передают X-ZhPath-User; сервер сравнивает его с авторизованной
сессией до чтения данных/записи попытки. Старый открытый экран не сможет отправить
ответы от имени аккаунта, вошедшего в другой вкладке.

Черновик имеет приоритет перед историей прошлых попыток. «Пройти заново» создаёт
пустой черновик, чтобы при перезагрузке не вернулся экран старого результата.
«Обновить тест» восстанавливает ответы, включая неподтверждённую отправку.
При несовпадении версий отображается объяснение; старые ответы не применяются.
Повреждённые записи и ошибки хранилища обрабатываются без падения интерфейса.

Перед отправкой requestId записывается вместе с ответами. Если запись невозможна,
запрос не отправляется: иначе после перезагрузки нельзя гарантировать повтор с
тем же ключом. При неопределённом результате отправки редактирование блокируется,
а повтор использует тот же requestId и тело запроса. Существующая уникальность
(userId, requestId) и проверка requestHash на сервере обеспечивают идемпотентность.
После подтверждённого результата черновик удаляется. Учебный контент, схема БД
и исторические результаты не изменяются.

## Автоматические проверки

- `npm run typecheck`, `npm run server:build`, `npm run build`, `npm run test:i18n`.
- `node --test dist-server/quiz.test.js` — 6 тестов проверки заданий/ответов.
- `node --test scripts/test-quiz-session.mjs` — реальный контроллер с двойником БД:
  смена сессии, повтор запроса, отклонение изменённого тела повторной отправки.
- `node scripts/test-quiz-draft.cjs` — React DOM в jsdom, API со сценариями отказов:
  перемонтирование как при перезагрузке/повторном входе; смена аккаунта;
  «Обновить тест»; отсутствие сети; потеря ответа после записи результата;
  одинаковые requestId/тело при повторе; очистка после успеха; повторное прохождение
  поверх истории; изменение обеих версий; ru/kk/en; отказ хранилища; все шесть
  типов ответа, включая незавершённые order/match; повреждённый JSON;
  подмена владельца записи; заголовки аккаунта в реальном клиенте API.
  Это DOM-проверки, а не ручной прогон в браузере.

Тестовый jsdom установлен отдельно, без изменения зависимостей приложения:

```powershell
npm install --prefix outputs/quiz-test-runtime --no-audit --no-fund jsdom
node scripts/test-quiz-draft.cjs
```

Для интеграции с PostgreSQL (существующая локальная схема, отдельные временные
пользователи/уроки, очистка после каждого теста):

```powershell
$env:APP_ORIGIN="http://127.0.0.1:8443"
node --env-file=.env --test --test-timeout=30000 --test-concurrency=1 --test-name-pattern="quiz requests reject|quiz submissions are idempotent|quiz gates completion|editor quiz changes preserve" dist-server/learning.test.js
```

## Результат 14.10.2026

Все перечисленные проверки прошли: 6 тестов оценивания, 2 теста контроллера,
4 интеграционных теста с PostgreSQL и DOM-сценарии на трёх языках.
В тестовом teardown закрываются оставшиеся HTTP-соединения, чтобы ошибочный
запрос не подвешивал завершение теста. Для существующих интеграционных тестов
Origin задаётся явно; .env не менялся. Контейнер zhpath-db-1 оставлен работающим.
Сборка сообщает предупреждения Vite о конфигурации и размере чанков; ошибок нет.
