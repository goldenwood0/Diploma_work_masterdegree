# Аудиокомплект ZhPath HSK 1 — 22.10.2026

Собраны **10 из 10 словарных записей**. Это локальный комплект для проверки,
не публикация и не подтверждение преподавателя. Четыре полных диалога пока отсутствуют.

## Послушать

Актуальный архив с подробным заданием дикторам: [hsk1-audio-review-v2.zip](../hsk1-audio-review-v2.zip).
Прежний архив сохранён отдельно.

Откройте `index.html` в браузере. После распаковки архива держите папки `wav/`
и `original/` рядом с этим файлом: интернет для воспроизведения WAV не нужен.
Адрес http://127.0.0.1:8766/ использовался ранее для статического предпросмотра;
на текущем этапе сервер на нём не запущен. Это не адрес приложения ZhPath.

На странице: каждый иероглиф/слово, pinyin, ru/kk/en, плеер, автор, лицензия,
ссылка на страницу источника, оригинал и WAV. Поля преподавателя изначально
«Не проверено». Проверяющий заполняет имя и решения и скачивает JSON; форма
не отправляет данные на сервер и не изменяет опубликованные уроки.

`CREDITS.md` содержит индивидуальные ссылки и версии страниц. `commons-discovery.json`
сохраняет полученные от Commons сведения об авторах/лицензиях/файлах и результаты
поиска. В Tatoeba поиск с аудио не дал точного «我叫安娜»; результат для
«你叫什么名字» содержал другую реплику «你堂兄叫什么名字？» и был исключён.
Отсутствие найденной записи не означает, что её нигде нет.

## Проверки и ограничения

- Скачаны оригиналы и 10 PCM 16-bit WAV. SHA-1 оригиналов совпадает с Commons;
  SHA-256 подготовленных WAV зафиксирован в manifest.json.
- Формат и ограничения медиатеки проверены реальным `wavDuration` приложения;
  тишины вместо речи и отсчётов на границе цифрового клиппинга не обнаружено.
- В браузере все 10 WAV загрузили метаданные; у первой записи проверен запуск
  плеера. Это не оценка произношения на слух и не проверка физического динамика.
- `不客气` заметно тише остальных по RMS (-27,2 dBFS). Перед демонстрацией
  проверить слышимость; громкость автоматически не нормализовалась.
- У 谢谢 продолжительность декодированного файла — 1,35 с; метаданные Commons
  сообщают около 0,92 с. Контрольная сумма оригинала совпала; в интерфейсе
  показана измеренная продолжительность WAV. Обрезки не выполнялось.
- Все языковые решения остаются `PENDING_HUMAN`. Отдельно проверить тоновую
  конвенцию 不客气 и нейтральные слоги; переводы перенесены из учебного снимка.

## Подключение в ZhPath

Актуальный конкретный план с проверкой окружения и версий:
[INTEGRATION.md](../INTEGRATION.md). Он охватывает 10 загрузок, пять черновиков
и 13 ссылок, включая два диктанта. Запись в БД не выполнялась.

Файл `proposed-content-with-audio.json` содержит пять валидных **файловых черновиков**
на основе подготовленной редакции 6/6/6/6 + 10 вопросов. Добавлены отдельные
аудиоблоки сразу после словарного блока; 名字 используется в двух уроках,
но скачан один файл. Готовых озвученных диалогов файл не заявляет.

Сейчас аудиоблоки ссылаются на неизменённые HTTPS-оригиналы Commons.
Для собственного хранения редактор должен загрузить WAV в медиатеку и заменить
audioUrl на возвращённый `/api/media/<id>/file`. Точные поля формы для каждого
файла находятся в `manifest.json` → `assets[].metadata`. Сведения о конвертации
и CREDITS следует сохранить вместе с комплектом. В этой работе записи медиатеки
и черновики БД **не создавались**, поскольку комплект оставлен для проверки.

После загрузки сопоставить:

| Урок | Словарные аудиоблоки |
|---|---|
| hsk1-greetings | 你, 好 и имеющийся 你好 |
| hsk1-my-name | 我, 叫, 名字 |
| hsk1-your-name | 什么, 名字 |
| hsk1-courtesy | 谢谢, 不客气, 再见 |
| hsk1-module-test | Существующий диктант 你好; при переносе в медиатеку заменить и его URL |

Не переносить локальный путь Windows в audioUrl. Не менять published/revision
или результаты пользователей напрямую. Перед сохранением сверить baseRevision
и baseEditVersion с действующим уроком; чужой черновик не перезаписывать.
Публикация после приёмки — отдельное решение пользователя.

## Воспроизвести техническую проверку

Из корня репозитория: `node scripts/test-hsk1-audio.mjs`.
Пересборка страницы: `node scripts/build-hsk1-audio-review.mjs`.
Повторное скачивание не требуется. Служебный ffmpeg установлен отдельно в
`outputs/hsk1-audio-tools`, зависимости приложения не менялись.
