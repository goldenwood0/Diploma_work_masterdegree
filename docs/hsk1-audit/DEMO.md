# Демонстрация пилотного модуля (12–15 минут)

Сверка 22.10.2026: действующее содержание подтверждено чтением БД; 47 серверных
тестов и DOM-проверки пройдены заново. Для локального показа работает **preview
собранного приложения** на 8443, API на 3001. Dev Vite в этом окружении зависает
на обработке запросов; не переключаться на него непосредственно перед показом.
Запуск после сборки: `npm run preview -- --host 127.0.0.1 --port 8443 --strictPort`
при свободном 8443. API запускать с `ZHPATH_TUTOR_ENABLED=false` и
`REMINDERS_ENABLED=false` в окружении процесса, не переписывая .env.
Проверка: `node --env-file=.env scripts/check-local-session.mjs`.

Перед физическим показом отдельно пройти: вход демо-ученика → четыре урока →
финал → SRS; прослушать 你好 и тихое 不客气 из отдельного комплекта на колонках
показа; проверить разрешение микрофона, запись/удаление, палец/стилус, масштаб и
узкий экран, китайский ввод и доступ к внешнему аудио. Пока это не принято.
ИИ в текущем запуске отключён: не обещать живой ответ при исчерпанной квоте.
План новых материалов показывать отдельно: [INTEGRATION.md](INTEGRATION.md).

Сценарий относится к **текущей версии**: 4 урока по 2 вопроса, финал из 6.
Черновик 6/6/6/6 + 10 показывать отдельно как подготовленный материал для приёмки.
Не заявлять, что он уже доступен ученикам или что весь HSK 1 завершён.

## Подготовка

1. Использовать отдельного демонстрационного ученика с пустым прогрессом, не чужой
   рабочий аккаунт. Не сбрасывать результаты существующего пользователя.
   Если такого аккаунта нет, создать его штатно заранее при рабочем SMTP либо
   подготовить изолированное демо-окружение; не обходить подтверждение email.
2. Проверить `http://127.0.0.1:8443`, API `/api/health`, наличие четырёх уроков и теста.
   Инструкция запуска — ../LOCAL_RUN.md. Не запускать seed для «восстановления» уроков.
3. Выбрать ru, затем проверить переключение языка объяснений отдельно от интерфейса.
   Подготовить китайскую клавиатуру или приведённые ниже ответы для вставки.
4. Проверить звук 你好, громкость, микрофон и возможность удалить запись. Если
   воспроизведение недоступно, показать сообщение ошибки и прямо назвать ограничение;
   диктант без прослушивания не выдавать за проверку аудирования.

## Показ

| Время | Действие | Ожидаемый результат |
|---|---|---|
| 0:00–1:00 | Открыть каталог и назвать цель: приветствие, представление, имя, благодарность, прощание | Доступен первый урок; следующие закрыты. HSK 2–6 без новых материалов |
| 1:00–3:00 | Урок 1: слова, правило тонов, запись 你好; переключить скорость, транскрипт и перевод; при готовом микрофоне записать/прослушать/удалить приветствие | Изучаемая реплика совпадает с видимым текстом; запись голоса — самопроверка |
| 3:00–4:00 | Завершить блоки, в тесте выбрать 再见 вместо 你好, в диктанте ввести 你好 | 1/2, тест не пройден, видны объяснения; урок 2 закрыт |
| 4:00–5:00 | Пересдать с двумя правильными ответами; обновить страницу | Результат восстановлен, урок завершён; доступны каталог и повторение, урок 2 открыт |
| 5:00–6:30 | Урок 2: 我叫安娜, мини-диалог; тест: 我→я, 叫→зваться, 名字→имя; пропуск 叫 | 2/2, открывается урок 3; перевод зависит от языка объяснений |
| 6:30–8:00 | Урок 3: вопрос и ответ; тест: 你 / 叫 / 什么 / 名字; ввод 名字 | 2/2, открывается урок 4. Можно показать восстановление частичного ответа после обновления до отправки |
| 8:00–9:00 | Урок 4: 谢谢 → 不客气, 再见; тест: 不客气 и 再见 | 2/2, открывается итоговый тест |
| 9:00–11:00 | Финал: пройти инструкцию и 6 заданий | Правильные ответы ниже; 5/6 достаточно для 80%, 4/6 недостаточно |
| 11:00–12:00 | Показать итог, обновить страницу, открыть «Повторить слова» | «Пилотный модуль завершён», результат сохранён; 10 уникальных слов, 名字 не повторяется |
| 12:00–13:00 | Открыть карточку, показать ответ, оценить «Хорошо» | Сохранено расписание следующего повторения; карточка уходит из текущей очереди. Учитывать лимит новых слов и часовой пояс |
| 13:00–15:00 | Показать аудит и отдельный черновик | Чётко отделены готовая техника, недостающее аудио и человеческая приёмка |

Ключи текущего финала в порядке вопросов: 你好; пары 我→я, 叫→зваться,
名字→имя; 你/叫/什么/名字; 叫; 再见; диктант 你好.
Для kk пары: мен / аталу / есім; для en: I / to be called / name.
Чтобы показать границу 5/6, ошибиться только в первом вопросе; остальные — верно.
В черновике финала другая граница: 8/10, не переносить инструкцию 5/6 на новую версию.

В SRS ожидаются: 你, 好, 你好, 我, 叫, 名字, 什么, 谢谢, 不客气, 再见.
Количество доступных сегодня карточек может быть меньше 10 из-за лимита или
предыдущих повторений демо-аккаунта; это не потеря слов.

«Это пилот из четырёх уроков, не полный уровень и не официальный экзамен HSK.
Технический маршрут проверен автоматически. Методическая приёмка и проверка
трёх переводов ещё не завершены. Сейчас озвучено только приветствие; диалоги
и новые задания подготовлены отдельно и не опубликованы».

Перед заявлением полной готовности провести этот сценарий на устройстве показа,
в том числе на узком экране, прослушать аудио и получить подписи проверяющих.
API- и DOM-тесты из отчёта не заменяют эту репетицию.
