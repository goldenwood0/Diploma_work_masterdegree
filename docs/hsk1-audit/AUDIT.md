## Исправления кода

1. `collectWords` проверяет совпадение версии завершённого урока с текущей.
   Раньше новые слова опубликованной версии могли попадать в SRS по старому завершению.
2. Завершение урока без теста добавляет слова в той же транзакции; раньше для этого
   требовалась последующая синхронизация словаря. Карточки добавляются без перезаписи
   заметок, расписания и истории существующих карточек.
3. Экран завершения различает урок и пилотный модуль и даёт явные следующие действия.
   Загрузка урока обновляется при смене userId.
4. В плеере убрана фиксированная подпись Wikimedia Commons для любого источника:
   показываются фактический автор, ссылка и лицензия записи.

Изменений схемы и миграций для приложения нет. Результаты существующих пользователей,
учебные версии и опубликованные уроки не изменялись. Seed не запускался:

## Правила применения после решения

В текущей БД `published=true`, `editorialState=DRAFT`, `draft=null` у стартовых уроков.
Это наследие seed: фактическая доступность определяется published, а не подтверждённой
приёмкой преподавателя. Не трактовать этот набор полей как разрешение публикации.

После приёмки редактор создаёт независимый черновик поверх текущего урока и сверяет
актуальные версии; переносит проверенный объект; отправляет на REVIEW. ADMIN
публикует только после отдельного решения пользователя и проверки аудио/прав.
Изменение содержания или теста увеличит учебную revision: прежние попытки останутся,
но для новой версии прохождение потребуется заново. При требовании сохранить
текущие зачёты без изменения учебного статуса новую редакцию следует демонстрировать
в отдельном окружении/копии курса, а не заменять действующие уроки.

Сейчас решения о публикации не запрашивается: комплект сначала должен пройти
перечисленные человеческие проверки. Наличие подготовленного JSON не даёт права
на автоматическую публикацию. Полный импорт уроков через UI пока не реализован;
перенос требует редактора или отдельного согласованного инструмента с проверкой версий.
