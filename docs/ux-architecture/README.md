## Что изменилось по сравнению с ПР4

| ПР4 | Сейчас (сайт и v2) | Почему |
| --- | --- | --- |
| «Профиль → Прогресс, Настройки», а на сайте статистика была на Главной | Статистика перенесена в Профиль → «Прогресс»; на Главной — сводка и ссылка «Весь прогресс» | Совпадает с картой сайта; Главная отвечает на «что делать дальше» |
| «Повторение → Карточки слов»; на сайте страница называлась «Словарь и повторение» с разделом «Мой словарь» | «Повторение» и «Мои карточки»; ссылка «Весь словарь» ведёт в раздел «Словарь» | Два разных «словаря» путали |
| «Назад из урока — к поиску»; на сайте «Курсы» сбрасывали поиск и фильтры | Каталог помнит запрос, уровни, статус и сортировку в пределах вкладки | Возврат в то же место |
| Тест: «ответить на 5 вопросов» и отправить | «Проверить» после каждого ответа, «Верно / Неверно», «Объясни ошибку» (ИИ), затем «Завершить тест» | Мгновенная обратная связь (этап 4) |
| Тест и результат — отдельные экраны | Внутри страницы урока | Согласованное отличие от макетов ПР6 |
| ИИ-помощника нет | Кнопка в шапке на любом экране; «Разобрать ошибки с ИИ» в результате | Тема диплома |
| — | Раздел преподавателя по роли: уроки, медиатека, пользователи | Ученик его не видит |

## Как пересобрать и загрузить в Figma

```powershell
node scripts/ux-architecture.mjs
```

```powershell
node scripts/ux-architecture-png.mjs
```

Первая команда пишет `svg/`, `design.json` и плагин `figma-plugin/`, вторая —
PNG через Microsoft Edge в фоновом режиме.

Импорт в Figma (десктоп-приложение): открыть файл макетов → Plugins →
Development → Import plugin from manifest… → выбрать
`docs/ux-architecture/figma-plugin/manifest.json` → запустить «ZhPath ПР4 v2
import». Плагин создаёт новую страницу «ПР4 · v2 (как на сайте)» и не меняет
существующие страницы. Сетевой доступ плагину не нужен.
