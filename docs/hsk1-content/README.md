## Чего нет

- **Аудио** для уроков 5–12: нужны записи с подтверждёнными правами
  (см. [../hsk1-audit/audio/RECORDING_BRIEF.md](../hsk1-audit/audio/RECORDING_BRIEF.md)).
- **Проверки преподавателем.** Казахские тексты писал не носитель языка.
- Раздел в каталоге один — «Первое знакомство»; разделы создаются только
  seed-скриптом, поэтому уроки 5–12 идут в нём же.

## Как опубликовать после проверки

1. Исправить замечания в админке («Управление уроками») или в
   `scripts/hsk1-module2.mjs` (тогда перегенерировать и сравнить).
2. Для каждого урока по порядку: «На проверку» → «Опубликовать» (нужна роль ADMIN).
3. Публикация новой версии урока 1–4 увеличивает его ревизию: прогресс учеников
   по этому уроку начинается заново, а следующие уроки закрываются до повторного
   прохождения. Для пилота без учеников это не важно; при живых учениках
   публиковать модуль 1 одним разом.
