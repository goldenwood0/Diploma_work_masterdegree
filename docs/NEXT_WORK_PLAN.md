  отмена/фокус/Escape/unconfigured, 10 успешных запросов и ограничение 11-го.
  Просмотрены ru/kk/en × 320/768/1280 (высота 900), DOM без горизонтального

## Приоритет 0: восстановить воспроизводимый запуск

Ниже исходные препятствия, выявленные до исправления. Приоритет 0 выполнен
30.09.2026; актуальные проверки и состояние процессов — в разделе «Продолжение».

1. В исходной .env DATABASE_URL указывал на 127.0.0.1:5432. Docker zhpath-db-1
   опубликован на 5433; слушатели есть на обоих портах. Принадлежность базы 5432
   проекту не подтверждена. Сначала read-only сверка схемы и происхождения баз;
   затем отдельно согласованная корректировка подключения, без миграций/seed.
2. getConfig() с исходной .env возвращал `Invalid server environment: SMTP_HOST`.
   Даже при выключенных напоминаниях это обязательное поле. Определить настройки
   локального запуска и отдельно согласовать их восстановление. Наличие настройки
   SMTP не даёт разрешения отправлять письма; REMINDERS_ENABLED остаётся false.
3. API-ключ сохранён, ZHPATH_TUTOR_ENABLED=true включён с разрешения пользователя.
   Ключ показан на снимках; его отзыв/замену новым должен выполнить пользователь.
   Не использовать показанный ключ, не переносить его в документацию.
4. Обновить устаревшие утверждения журналов о том, что ключ отсутствует и флаг
   не включён. Сохранять прежние результаты как исторические.

Результат: выбранная база и серверное окружение подтверждены, API запускается,
health и сессия работают, рассылка выключена. Наличие ключа само по себе не
подтверждает его действительность, доступ к модели или оплаченный баланс.
