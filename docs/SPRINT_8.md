## Реализовано — 29.09.2026

- `GET /api/tutor/status`, `POST /api/tutor/ask`: существующие SessionGuard и
  OriginGuard, строгая схема. Нельзя передать userId, уровень, язык или system-роль.
- Сервер выбирает опубликованный урок по slug, проверяет prerequisite и его

  поиск по всей программе. При возврате назад в UI контекст остаётся на серверной

- Из материала берутся только разрешённые учебные поля. draft, email, имя,

  Из свободного текста дополнительно удаляются распознаваемые email и типовые
  ключи/токены/пароли; это не универсальный классификатор персональных данных.
- Четыре режима панели подключены к API. Есть загрузка, отмена, повтор после
  ошибки, новая беседа, Escape/focus loop, сброс при смене урока/языка/аккаунта.
  История — только в памяти панели. Без урока предлагается открыть урок;
  без провайдера показано отсутствие настройки и отправка отключена.
  Тестовые ответы явно подписаны, прежнее ложное «В сети» удалено.
- Лимиты: 10 запросов/минуту на пользователя, 1 активный запрос на пользователя,
  20 одновременно на процесс, 1500 символов сообщения, 6 ходов истории по 2000,
  8000 символов материала, 16000 сериализованного контекста, 6000 ответа,
  1200 выходных токенов. Дедлайн 20 секунд охватывает получение контекста и
  провайдера. HTTP disconnect отменяет provider signal; чтения Prisma сами
  по себе не прерываются, их поздний результат не отправляется провайдеру.
- OpenAI-адаптер: фиксированные endpoint и модель `gpt-6-luna`, серверный ключ,
  Responses API, `store:false`, без инструментов, `reasoning.effort:none`,
  `service_tier:default`, без автоматических повторов/редиректов. Вход максимум
  70KB, ответ читается с ограничением 64KB до JSON parsing. Отказы, tool calls,
  незавершённые/невалидные ответы и provider errors не выдаются за учебный ответ.
- Учёт: ограниченный журнал исходов в памяти; достоверный provider usage

  OpenAI не возвращает здесь фактический счёт в USD: стоимость не выдумывается.
  Поле cost общего контракта допустимо только для достоверной суммы провайдера.

## Бюджет и предложение по включению

Одобрен общий потолок $5, а не $5 на каждый запуск. `logs/tutor-budget.json`
хранит консервативный резерв: 2 цента на каждую исходящую попытку, до 250 попыток.
Это **резерв, не фактическое списание**. Ошибки и отмены резерв не возвращают,
поскольку отмена не гарантирует отсутствие списания у провайдера. Журнал атомарно
записывается до вызова; exclusive lock предотвращает параллельный перерасход.
Повреждение журнала и занятый/оставшийся lock блокируют вызовы. Удаление журнала
сбросит учёт, поэтому его нельзя удалять как обычный лог, в том числе при деплое.
При переносе сервера нужен тот же журнал и тот же общий бюджет.

Резерв рассчитан с запасом по [тарифу GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)
на 29.09.2026: Standard $0.10/M input, $0.125/M cache writes, $0.50/M output,
при ограничениях размера выше. Изменение модели, тарифа, уровня обслуживания или
ограничений требует пересмотра резерва; это не ограничитель всего OpenAI-аккаунта,
налогов и сторонних вызовов. Документация API:
[генерация текста](https://developers.openai.com/api/docs/guides/text).

Проверено только наличие `OPENAI_API_KEY`: отсутствует. Значения секретов не
выводились. Конфигурация не менялась. Конкретный следующий шаг, **только по
отдельному запросу на настройку**: пользователь добавляет ключ в серверное
окружение (без `VITE_`, без чата), включается `ZHPATH_TUTOR_ENABLED=true`.
Нужен доступ на запись к сохраняемому `logs/`. При отсутствии любого из двух
параметров используется unconfigured; тестовый адаптер в production app не включается.
После настройки сначала проверить один временный урок с реальным провайдером,
сверить provider usage и журнал бюджета, затем оценить ru/kk/en с преподавателем.
