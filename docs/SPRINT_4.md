# Спринт 4 — упражнения и тесты

Завершён локально 10.09.2026. Четыре урока получили тесты по два задания,
после них доступен отдельный итоговый тест модуля из шести заданий.

## Возможности

- Выбор ответа, сопоставление, порядок слов, пропуск, ввод и диктант.
- Серверная проверка; правильные ответы и объяснения не выдаются в форме теста.
  После отправки доступны собственный ответ, правильный ответ и объяснение ru/kk/en.
- Порог 80%: в тестах из двух заданий нужны оба ответа, в модуле — пять из шести.
  Все задания имеют одинаковый вес; сопоставление оценивается целиком.
- Прочитанные блоки сами по себе не завершают урок с тестом. Успешный тест
  завершает урок и открывает следующий; последующая неудачная попытка не отменяет зачёт.
- Попытки хранят ответы, результат, версии урока/теста и снимок заданий с ключами.
  В интерфейсе доступны последние десять попыток; в БД сохраняются все.
- Повтор запроса с тем же requestId возвращает существующий результат.
  Изменённое содержимое с тем же ключом отклоняется. Конфликт параллельных
  транзакций возвращает 409; повторное нажатие сохраняет тот же ключ.
- Новый тест с устаревшими версиями не принимается. История показывает исходные
  формулировки и результат, даже если редактор изменит текущий тест.

## Запуск и обновление

Остановите локальный API перед генерацией Prisma Client на Windows:

```powershell
pnpm db:generate
pnpm db:deploy
pnpm server:build
pnpm db:seed
pnpm server:dev
```

Фронтенд: `pnpm dev`, http://127.0.0.1:8443. Docker с PostgreSQL должен работать.
Seed добавляет тесты один раз. При первом добавлении увеличивается версия урока:
прочитанные блоки сохраняются, но прежнее завершение чтением заменяется требованием
пройти тест. Следующие запуски seed не меняют версии, прогресс и попытки.
Существующие тесты seed не перезаписывает.

API: `GET /api/learning/lessons/:slug/quiz` и
`POST /api/learning/lessons/:slug/attempts`. Отправка содержит `requestId` (UUID),
`lessonRevision`, `quizRevision`, `answers: [{ questionId, value }]`.
Для сопоставления value — массив идентификаторов правой колонки в порядке левой;
для порядка слов — массив идентификаторов слов; остальные ответы — строки.
Сессия и CSRF-проверка обязательны. Идентификатор пользователя сервер берёт из сессии.

## Проверки и ограничения

21 автоматическая проверка: авторизация, прогресс, доступ к тесту, отсутствие ключей
в форме, провал/зачёт, история в другой сессии, повторы и параллельные запросы,
подмена ответа, устаревшие версии, все шесть типов и порог оценки.
Типы frontend/backend, 209 ключей локализации и production-сборка проходят.
В браузере заполнены все шесть типов, получен результат 6/6 и проверено
восстановление результата после обновления. Повтор seed сохранил попытку.

Свободный ввод проверяется по явно перечисленным ответам. Пробелы, пунктуация,
регистр и Unicode-ширина игнорируются; тоны и порядок символов сохраняются.
Синонимы и свободные предложения автоматически не оцениваются.
Черновик ответов до отправки хранится только в текущем экране.
Это учебные тесты с повторными попытками, не защищённый экзамен.
При редакторском изменении теста необходимо увеличить его revision; если нужен
повторный зачёт, увеличить и revision урока. Админка будет в спринте 6.

Диктант использует ту же лицензированную запись «你好», что и спринт 3;
атрибуция размещена у плеера. Методическая и языковая проверка материалов остаётся
перед выпуском. Vite предупреждает о размере общего JS-файла и будущей загрузке
конфига; ошибок сборки нет.
