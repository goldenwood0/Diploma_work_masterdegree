# ИИ-помощник на локальной модели (Ollama)

ИИ-помощник может работать без OpenAI: на модели, запущенной на этом
компьютере через [Ollama](https://ollama.com). Ключ и оплата не нужны, данные
уроков и тексты ученика не уходят с компьютера. Сервер принимает только
локальный адрес (`127.0.0.1`, `localhost`, `[::1]`).

Код: `server/tutor-ollama.ts`, тесты: `server/tutor-ollama.test.ts`.
Режимы, лимиты запросов и защита от подмены инструкций — общие с OpenAI.
Тайм-аут ответа для локальной модели — 90 с (у OpenAI — 20 с): первая загрузка
модели в память видеокарты занимает время. Бюджет $5 к Ollama не применяется,
токены по-прежнему учитываются в статистике сервера.

## Установка (один раз)

1. Установить Ollama для Windows с ollama.com (около 1 ГБ).
2. Скачать модели (около 5 ГБ каждая; для RTX 4050 6 ГБ подходят 7–8B):

```powershell
ollama pull qwen2.5:7b
```

```powershell
ollama pull llama3.1:8b
```

Модели без режима «размышлений» (qwen2.5, llama3.1) отвечают быстрее и
не тратят лимит токенов на скрытые рассуждения.

## Включение

Добавить в `.env` (или задать в терминале перед запуском API):

```
ZHPATH_TUTOR_ENABLED=true
ZHPATH_TUTOR_PROVIDER=ollama
ZHPATH_OLLAMA_MODEL=qwen2.5:7b
# ZHPATH_OLLAMA_URL=http://127.0.0.1:11434
```

Без `ZHPATH_TUTOR_ENABLED=true` ИИ выключен. `ZHPATH_TUTOR_PROVIDER=openai`
(по умолчанию) возвращает работу через OpenAI, для него нужен `OPENAI_API_KEY`.

Проверить, что Ollama запущена и модель на месте:

```powershell
ollama list
```

## Ограничения

- Малые модели ошибаются в тонах пиньиня и хуже держат инструкции, чем
  крупные облачные. Ответы нужно проверять с преподавателем.
- Казахский язык у моделей 7–8B слабый; ответы на kk проверять отдельно.
- На защите Ollama должна быть запущена на том же ноутбуке, что и API.
